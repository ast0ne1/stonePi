{{ svg("platform") }} Two update channels

OS security (Debian/Raspberry Pi packages) installs automatically via unattended-upgrades — security pocket only, no automatic reboot. Firmware/major OS upgrades stay manual (Cockpit).

StonePi apps & platform are controlled here: GitHub release zips checked and installed one at a time. Run a USB backup (or restore drill) before a platform zip.

{{ svg("github") }} GitHub repository

Release assets should be named like stonepi-<app>-<version>.zip (e.g. stonepi-newscast-<version>.zip) or stonepi-platform-<version>.zip, with a SHA256SUMS file alongside them.
